How it works
The extension scans streaming sites for movie/show cards, extracts titles, then fetches ratings from the OMDB API and overlays them as badges.
Built-in sites
Netflix · Disney+ · Max (HBO) · Prime Video · Apple TV+ · Hulu
Adding new sites
Go to Sites → add a custom site → use 🎯 Pick Element to click a movie card directly on the page to auto-generate a CSS selector.
Badge colours
🟢 ≥ 7.5   🟡 6–7.4   🔴 below 6
Click any badge to open its IMDb page.
